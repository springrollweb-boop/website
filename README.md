# Spring Roll Station website

Static website for Spring Roll Station, Vietnamese restaurant in Singapore (Novena and Skysuites at Anson).

- The site itself is in `site/`. Serve that folder as is on any static host.
- `build-pages.py` assembles the four pages from shared header and footer parts. Run `python3 build-pages.py` after editing it.
- See `site/README.md` for how to edit the menu, add photos and run it locally.
